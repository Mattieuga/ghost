# Design

Fixture documents for looking at Ghost's own rendering: typography, spacing, and Markdown round trips. Open them in Ghost when changing fonts, themes, or the serializer.

For the role of this folder in the docs taxonomy, see [`docs/README.md`](../README.md).

## Index

- [`typography-showcase.md`](./typography-showcase.md) — a repeatable document covering headings, lists, quotes, code, tables, and frontmatter, for comparing fonts and checking that a save leaves the file unchanged.
