# Reader regression fixtures

- `epub-reader.epub`, `epub-reader-legacy.epub`: original Ghost EPUB 3/2 fixtures.
- `ebook-reader.fb2`: original Ghost two-chapter FictionBook fixture.
- `comic-reader.cbz`: original Ghost red, green and blue PNG pages, with out-of-order filenames to test natural ordering.
- `alice-gutenberg.mobi`, `alice-gutenberg.azw3`: Project Gutenberg #11, Alice's Adventures in Wonderland by Lewis Carroll. Downloaded 2026-09-06 from https://www.gutenberg.org/ebooks/11.kindle.images and https://www.gutenberg.org/ebooks/11.kf8.images. The catalogue identifies this work as public domain in the USA; the files retain their supplied Project Gutenberg notices. https://www.gutenberg.org/ebooks/11

Full click-through samples were downloaded separately to the owner's requested `/Users/matt/code/ghost/example test files` folder and are not bundled into the app.
